# Админский Клиент Flandosync

Админский клиент - отдельная PyQt-утилита для обслуживания сервера Flandosync по SSH.

Он не открывает публичный admin HTTP API и не использует ключи игроков для админских действий.

## Запуск Из Исходников

```bash
python -m pip install -r requirements.txt
python admin_client.py
```

Скопируй и отредактируй настройки:

```bash
cp admin_settings.example.json admin_settings.json
```

## MVP Возможности

- Проверить SSH-доступ.
- Показать список сборок на сервере.
- Сгенерировать manifest для выбранной сборки.
- Указать версию manifest.
- Указать короткий changelog.
- Опционально перезапустить настроенный systemd-сервис.

## Безопасность

Клиент запускает только узкие заранее заданные команды. Это не удаленный терминал.

Рекомендуемая настройка сервера:

- Использовать отдельного SSH-пользователя.
- По возможности ограничить пользователя папкой проекта Flandosync.
- Не использовать ключи игроков как админские credentials.
- Не публиковать `admin_settings.json`, SSH-ключи, реальные hosts и production-пути.
